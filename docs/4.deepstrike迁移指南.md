# docs/4 — deepstrike 迁移指南（交接参考；插件适配暂缓，另行立项）

> 现状：deepstrike 的 `db_exploit` 插件（`packages/exploit/mdut.ts`）仍对接 Extend-1.3.1 GUI/CLI 混合 jar；
> 本项目 v3+ 已按《docs/2.CLI二开实施方案.md》完成纯 CLI 化，**契约已破坏性变更**。
> 本文仅给「届时如何切到 mdut-cli」的判据与映射，不构成本项目交付义务。

## 1. 通路判定

| 判据 | 结论 |
|---|---|
| `ExploitExecutor`/`ctxShellExecutor` 通路 | **原样可换**：仍是 `java -jar`/脚本 argv；推荐直接 `cli/mdut`（自带 task 解析与守卫），或 `java -jar mdut.jar`（task 显式传 `--task`） |
| `cordis.patch.yml` 的 `mdutJarPath` | 指向新版 `mdut.jar` + 旁挂 `Driver/`、`Plugins/` 目录（同层） |
| 输出判定 | `looksLikeError` 文本兜底**可废**：改读退出码（0/2/3/4/5）+ 信封 `ok` 字段（stdout 恰好一行 JSON） |

## 2. action → 子命令映射

| deepstrike action（现状） | mdut-cli 落点 |
|---|---|
| connect（各库 add + 试连） | `add <type> --host --port [--user --pass --db]`（信封 `id` 即 connection_id；失败 exit 3/4） |
| special: exec | `exec --id <id> [--method ...] <cmd>`；redis 主从补 `--vps-host/--vps-port` |
| special: query（原生 SQL） | `sql --id <id> "<sql>"`（兼容形式 `--sql` 仍在） |
| special: file 系列 | `list-files/read/write/upload/download/rm/mkdir`（大文件 `download --out`/`upload` 直存直传） |
| special: revshell | `revshell --id <id> <ip> <port>` |
| special: proxy 引导链（NoRouteToHost → 教 users 起隧道） | `--proxy socks5://...` + hint 已内置引导；**add 时登记的代理后续命令自动回放** |
| 清理 | `clean`（mssql 另有 `recovery`）；上层 job 收尾调 `delete <id>` 清连接记录 |

## 3. 破坏性变更清单（对现有插件的 diff 面S）

1. **无 config.yaml**：驱动/URL 全部内置（`Util/JdbcProfiles`）；任何 yaml 生成逻辑删除。
2. **connection_id 作用域 = task 级**：engagement ↔ `--task` 一一映射；同号跨任务是不同连接。
3. **mongodb 独立 add 类型**（`add mongodb` + `info`），不再走 mysql 兼容形态。
4. **文件删除命令是 `rm`**（`delete` 保留给连接记录）——旧插件如映射过 `delete <path>` 需改。
5. **输出契约**：stdout 恒一行 JSON（`--format text` 除外）；日志全走 stderr；解析按 JSON 而非文本嗅探。
6. **测试锚点**：`tests/exploit.test.ts` 的 canned fixtures 全部重录（信封形状 + 退出码）。

## 4. 建议排期（另行立项时）

1. 以 `cli/tests/run.sh` golden 用例为插件验收母版复刻到 deepstrike 侧。
2. `parseConnectionId`（`/—\s*ID:\s*(\d+)/` 文本正则）替换为信封 `id` 字段读取。
3. `--task` 与 deepstrike engagement id 双向绑定（审计账可反查）。
4. 移除 Extend jar 依赖后，`/opt/tools/MDUT/` 可整体退役（Driver/Plugins 由本项目发布 zip 提供）。
